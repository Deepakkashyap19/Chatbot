# 🤖 AI Chatbot Web Application

Live Demo: [https://chatbot-1-pngn.onrender.com/](https://chatbot-1-pngn.onrender.com/)

## 📌 Project Overview

This project is a full‑stack AI Chatbot web application that allows users to interact with a conversational bot through a clean and responsive web interface. The chatbot processes user messages and returns responses dynamically using a backend API.

The application is built using modern web technologies including React for the frontend and Node.js for the backend.

---

## 🚀 Features

* 💬 Real‑time chatbot conversation
* ⚡ Fast and responsive UI
* 🎨 Modern interface using React
* 🔗 API communication between frontend and backend
* 📱 Fully responsive design
* 🌐 Deployed online using Render

---

## 🛠️ Tech Stack

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```
git clone https://github.com/Deepakkashyap19/Chatbot.git
```

### 2️⃣ Navigate to Project Folder

```
cd Chatbot
```

---

## ▶️ Run Backend

```
cd Backend
npm install
node server.js
```

Backend will start on:

```
http://localhost:5000
```

---

## ▶️ Run Frontend

Open a new terminal.

```
cd Frontend
npm install
npm run dev
```

Frontend will start on:

```
http://localhost:5173
```
